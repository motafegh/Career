# Career Review Log

**Owner:** Ali Rajabi  
**Status:** Approved Career review record  
**Responsibility:** Formal and event-triggered career-level questions, evidence inspected, conclusions, decisions, and next review triggers

## 1. Boundary

This log records career-level reviews only.

It does not record:

- ordinary project sessions or commits;
- project technical continuation;
- source or test details except when necessary to support a Career conclusion;
- every learning event;
- project blockers or working memory;
- private medical, legal, financial, credential, application, or personal correspondence.

Technical evidence remains in project repositories. Career records the resulting capability, portfolio, workload, employability, or strategy decision.

## 4. Review triggers

A new entry is appropriate when:

- a scheduled career-cycle review occurs;
- Ali requests a Career review;
- a project gate changes capability or portfolio interpretation materially;
- workload changes materially;
- a capability or portfolio claim is proposed;
- application readiness is evaluated;
- target roles, geography, or work mode change;
- a project is admitted, reclassified, paused, closed, or retired;
- a career cycle ends;
- a material Career governance decision occurs.

## 5. Maintenance

Add entries chronologically. Do not rewrite old decisions to match current state; add a new review that supersedes or corrects them.
