## 3. Strongest current portfolio story

JobHunter's strongest portfolio value is not simply "AI analyzes jobs."

Its better story is:

```text
employer source truth
→ deterministic source representation
→ bounded LLM/semantic interpretation
→ provenance-preserving structured output
→ mechanical validation
→ human semantic review
→ reject overclaim or deterministic defect
→ correct architecture/validator
→ regression evidence
→ only then promote current artifacts
```

The v7→v8→v9 Capability path and the later heterogeneous-role gate provide useful examples of this discipline.

On 2026-08-17, a new Python/software role (`tmBK`) exposed a multi-signal depth-canonicalization defect: one dense source segment contained several employer-explicit depth levels, while the deterministic validator incorrectly reused the first `Mastery` marker for later concepts. The candidate artifact was semantically rejected, no Capability artifact was allowed downstream, the deterministic validator was corrected, and a real regression was added.

This is a strong applied-AI reliability/evaluation case because mechanical completion was explicitly not treated as semantic acceptance.
