# Profile Area

This area contains durable profile context used by Career.

## Files

### `CAREER_PROFILE.md`

Concise governance-facing profile.

Use for stable public-safe facts, broad preferences, durable strengths/limits, and Career-level orientation without duplicating mutable capability or market state.

### `COMPREHENSIVE_PERSONAL_AND_PROFESSIONAL_PROFILE.md`

Detailed personal/professional profile.

Use when work depends on deeper context around:

- education;
- professional history;
- management / operational responsibility;
- communication / decision patterns;
- technical origin and exposure;
- AI-assisted engineering style;
- learning / motivation / execution patterns;
- career preferences;
- strengths, limitations, and unresolved questions.

The comprehensive profile is descriptive context, not a capability authority.

## Authority boundaries

- Current capability depth: `../tracking/CAPABILITY_EVIDENCE_LEDGER.md`
- Current Career position / exact next action: `../CAREER_STATE.md`
- Current role strategy: `../strategy/CAREER_STRATEGY.md`
- Current project roles: `../portfolio/PROJECT_PORTFOLIO.md`
- Current employability / market method: `../market/EMPLOYABILITY_AND_MARKET_PLAN.md`

Do not infer mastery, readiness, or ownership directly from profile narrative.
