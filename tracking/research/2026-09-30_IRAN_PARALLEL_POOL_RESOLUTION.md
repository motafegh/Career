## 2. Freshness rule strengthened

A platform/feed item being visible or freshly crawled is **not enough** to call a vacancy current/open.

Use this hierarchy:

```text
fresh employer-authored post / active native vacancy
> current platform listing with native detail
> recent aggregator/index existence
> feed/title-only discovery
```

If a feed links to a clearly old/closed native page, treat the feed as discovery noise rather than current-vacancy proof.

### Concrete counterexample

A Quera Telegram feed surfaced a Junior Python Developer item as if current, but following the Quera link opened a page dated 2022 and explicitly marked closed.

Therefore:

- Quera/Telegram feeds remain useful discovery instruments;
- current/open status requires native or employer verification before application;
- old cached redirect targets must not occupy active pool slots merely because the feed was recently crawled.
